# Scripta v1.2.0 — Release Highlights

- **LaTeX Document Support (`.tex`)**: Edit and live-preview LaTeX documents and math equations directly in the browser.
- **Collapsible Tab Groups**: Organize tabs into color-coded groups with drag-and-drop support and automatic session/workspace persistence.
- **Sample Files**: Quickly open starter sample files for supported languages via **Help → Sample Files** or by holding / right-clicking the **`+`** button.
- **Resources & Storage Manager**: Inspect and clear cached offline runtimes (Python, LaTeX, etc.) directly in **Settings → Preferences**.
- **Mermaid Preview Improvements**: Fixed mobile header overflow, added touch drag-to-pan and pinch-to-zoom on mobile, and enabled direct mouse-wheel zoom on desktop.
- **Quality of Life**: Added **Rename...** to the **File** menu and confirmation dialogs before resetting Preferences or Keyboard Shortcuts to defaults.
